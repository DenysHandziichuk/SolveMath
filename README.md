# 🔥 SolveMath

SolveMath is a platform that makes presenting math questions easier. With its technology and user-friendly interface, SolveMath is the perfect tool for students, teachers, and math enthusiasts.

## ✨ Key Features

* 📝 Interactive math lessons and exercises  
* 🤖 AI-powered math problem solver  
* 📊 Step-by-step solutions and explanations  
* 📈 Progress tracking and analytics  
* 🎉 Rewards and badges for achieving milestones  

---

## 🧭 Simple Workflow

1. Open the SolveMath app and log in or create an account  
2. Choose your preferred math topic to begin your learning journey  
3. Dive into interactive lessons and exercises tailored to your level  
4. Get real-time help from the AI-powered problem solver when stuck  
5. Track your progress with in-built analytics and earn rewards  

---

## 🎯 Purpose

SolveMath is designed to make presenting math questions easier. It provides an interactive interface, a graphics calculator, and a math problem solver to help users improve their math skills.

---

## 🧩 Installation & Usage

```bash
git clone https://github.com/DenysHandziichuk/SolveMath
cd SolveMath
npm install
npm run dev
```

---

## 🛠️ Tech Stack

SolveMath is built using Next.js, Tailwind CSS, and TypeScript, providing a fast and scalable platform for learning math.
